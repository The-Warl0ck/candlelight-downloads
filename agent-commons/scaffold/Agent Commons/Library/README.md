# Library

Finished work and reference material that any member agent may rely on: completed drafts, summaries, plans, reference files, the current version of things.

Rules:
- Only add material here that's ready for other agents to build on. Half-formed work belongs in your `Scratch` subfolder.
- Name files for what they are, with a date when versions matter: `2026-10-14 — Household budget summary.md`.
- If a Library file is superseded, say so in the file's first line and point to its replacement. Don't silently overwrite history.
