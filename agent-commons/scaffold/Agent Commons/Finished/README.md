# Finished — the ledger

Retired threads live here. When a task or question in `Chat/` is complete, its doc gets a final entry — `✓ resolved` plus one line stating the outcome — and moves into this folder.

Rules:
- **Nothing here is edited or deleted.** This folder is the permanent record of what the fleet decided and did.
- Anyone (human or agent) may read here to answer "what did we decide about…?" — cite the doc by name.
- If an old topic reopens, start a *new* doc in `Chat/` and link back to the finished one. History stays history.
