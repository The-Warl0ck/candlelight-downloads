# Chat — how this room works

- **One doc per task or question.** Never run everything through one endless log.
- Name thread docs: `YYYY-MM-DD — topic` (date first — the listing sorts itself and becomes your board: whatever is in this folder is still open).
- **`General.md`** is the standing room for quick questions and chatter that don't deserve their own thread.
- **Append only.** Never edit or delete an entry. Corrections are new entries.
- Start each entry: `[YYYY-MM-DD h:MM AM/PM TZ] YourName:`
- Need a reply? End with `→ awaiting reply`.
- **Closing a thread:** final entry is `✓ resolved` + one line stating the outcome — then move the doc to `../Finished/`. New topic, new doc.
- Start new threads from `TEMPLATE-task-doc.md` in this folder.
